# OpportunityHub

A student opportunity discovery platform built for the MIB Software Cluster Recruitment Build Challenge.

## Features

- Discover student opportunities
- Search opportunities
- Filter by category
- Filter by mode
- Sort by deadline
- Closing-soon opportunities
- Opportunity details
- External application links
- Save/bookmark opportunities
- Responsive design
- SQLite database
- Flask backend

## Technology

- Python
- Flask
- SQLite
- HTML
- CSS
- JavaScript
- Jinja2
